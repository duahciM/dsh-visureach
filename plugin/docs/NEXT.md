# Video observer 0.3

Computed tool calls return a compact source-bound preview and a `result_ref` by default. `evidence_detail` browses any field by path and cursor and supports repeated reads. Inliers, complete comparison sets, region similarity scores, and source-check diagnostics remain stored. Original PNG delivery and its coverage accounting use the existing native-resolution path.

`relation_figure2` runs the P2‑23 per-frame geometry graph on catalogue analysis pixels. `change_triggers` and `change_recheck` reuse P2‑17 comparison and held-out feedback against Agent-chosen source intervals and cadence. `appearance_search` evaluates direct SIFT matches from one exact anchor across the requested catalogue. Multiple hypotheses remain separate. The plugin does not merge physical scene or object identities, infer boundaries from missing matches, or use any scores to gate original source access. The installed wave keeps its existing navigation definition.

`evidence_reference` checks citation type and allowed scope. Original, derived crop, OCR, ASR transcript, embedded subtitle, source track metadata, computed output, and externally declared computation are distinct. Verification of a hash, source PTS, or parent link is independent of semantic support. A direct visual assertion requires a suitable visual reference for its scope. External declarations record provenance without claiming independent recomputation. Derived crops preserve their parent and coordinates and accept enlargement up to the configured payload envelope, separately from original image rules.

`observation_dispute` retains competing, source-supported interpretations on an append-only old revision. It leaves the dispute unresolved until reviewed; a subsequent revision does not erase earlier snapshots. Active ledgers write the new record to a separate replica, flush it, then flush the primary file. Reopen recovers the union, keeps a damaged copy for investigation, and checks the same journal ID for conflicting contents. It does not guarantee recovery if both files and the archives are lost.

Use `compactEvidence: false`, `researchNavigation: false`, or `activeJournal: false` to disable those changes independently. Existing options from `INTEGRATION.md` still apply. The versioned install and older data directories remain separate from the cache schema change. Raster analysis stays local. Real-time streams and full-video identity groups remain research.
