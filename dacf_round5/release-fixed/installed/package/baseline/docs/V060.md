# VisuReach 0.6.0 offline update

Use the catalogue, Figure 1/2, change triggers, wave, or unviewed axis to decide where to look. The catalogue keeps independent D1–D6 nominations from the base scan. Exact delivery and source resampling remain independent of those nominations. Optional local measurements, OCR, ASR, or CLIP provide scoped clues. The observer decides how to use evidence and when to stop.

Use integer source PTS for exact frame arguments and seconds for search bounds. Text summaries round seconds for readability. Use citation metadata for the recorded source time when querying a very narrow range. Each ROI is `[x, y, width, height]` in native pixels unless the schema explicitly asks for analysis coordinates. Replace the PTS, IDs and ranges below with those returned by your session.

| Need | Example | Interpreting results and recovering |
|---|---|---|
| Compare selected times | `evidence_routes({anchor_pts:12800,compare_to_pts:2560,channel:"catalogue"})` | Existing nomination roles and saved Figure 1/2 measurements at two distinct PTS. Equal roles do not make the views interchangeable. If a PTS is unknown, read it first or use the catalogue. |
| Find an object's recorded route | `evidence_routes({candidate_id:"<candidate_id>"})` | Lists explicitly linked views and states and comparisons saved with that candidate. Use `object_candidate` to recover the candidate ID. |
| Retrieve projected relations | `evidence_routes({channel:"computed",relation:"measured_projected_proximity",start:0,end:5})` | Relations from earlier `relation_figure2` calls. Each row indicates if it came from the frozen catalogue or the session. Use `evidence_detail` on the result reference for the full region and edge data. An empty result can mean the graph was never requested. |
| Check an observation history | `observation_review({revision_id:"<revision_id>",start:0,end:5})` | Resolves original and crop timestamps, saved calculation inputs and transcript intervals. The revision review shows explicit state links and stale dependencies. Broaden a range or omit it for untimed declarations. Text timing describes the text channel. |
| Recheck a cited crop parent | `claim_verify({evidence_ids:["<derived_id>"]})` | Re-decodes the original and compares the image receipt. It identifies the crop and its bounding rectangle. Inspect the crop separately when the claim concerns the derived pixels. |
| Recover from duplicate A/B references | `compare_object_views({mode:"direct",prototypes:[{pts:2560,native_xywh:[58,117,120,142]}],samples:[{pts:12800,native_xywh:[58,117,120,142]}]})` | If A and B were the same view, use one reference as above or select a distinct B. Luma MAD is the arithmetic mean of absolute residuals in 8-bit luma units. Reprojection medians use analysis pixels. |

Ask `observer_guide` for individual tool examples or the optional `comparison`, `state`, `contradiction`, `motion`, `recurrence`, `short_event`, and `final_check` topics. The examples describe available routes. Important visual claims remain checkable against the actual original or a declared crop of it.

For Windows installation, unpack the npm tarball into a new directory and point the Cordis configuration to its `index.js`. Python with OpenCV, NumPy and Pillow, and FFmpeg/FFprobe are required. Optional text and semantic channels retain the configuration in [V050](V050.md). This package defaults to a separate cache directory, `video-observer-offline-060`. Preserve your earlier package and cache to switch back. Existing 0.5.0 live simulation, protocol and entry point remain available.
